# mini12306 - 火车票务系统 Demo

基于 Spring Boot 的简易火车票务系统，支持用户注册、列车查询、购票与退票功能。

## 技术栈

| 项目 | 版本/技术 |
|------|-----------|
| JDK | 17 |
| 框架 | Spring Boot 4.0.6 |
| 构建 | Maven |
| 实用工具 | Lombok |
| 数据存储 | 内存（ArrayList） |

## 项目结构

```
demo/
├── src/main/java/com/example/demo/
│   ├── DemoApplication.java              # 启动类
│   ├── controller/
│   │   ├── HelloController.java          # 测试接口
│   │   ├── UserController.java           # 用户注册/查询
│   │   ├── TrainController.java          # 列车列表/搜索
│   │   └── OrderController.java          # 购票/退票/订单查询
│   ├── entity/
│   │   ├── User.java                     # 用户实体
│   │   ├── Passenger.java               # 乘客实体
│   │   ├── Train.java                    # 列车实体
│   │   ├── Order.java                    # 订单实体
│   │   └── Ticket.java                   # 车票实体
│   └── service/
│       ├── DataService.java              # 内存数据层
│       └── OrderService.java             # 购票退票业务逻辑
└── src/main/resources/
    └── application.properties            # 应用配置
```

## 快速启动

### 前置条件

- JDK 17+
- Maven 3.6+

### 启动命令

```bash
cd demo
mvn spring-boot:run
```

应用启动后在 `http://localhost:8080` 监听。

## API 文档

### 1. Hello 测试

```
GET /hello
```

响应：`"你好！这是你的第一个 Spring Boot 接口！"`

### 2. 用户注册

```
POST /api/users/register
Content-Type: application/json

{
  "username": "zhangsan",
  "password": "123456",
  "phone": "13800138000",
  "realName": "张三",
  "idCard": "110101199001011234"
}
```

> 5 个字段都是必填，username 不能为空。

响应：
```json
{
  "id": 1,
  "username": "zhangsan",
  "password": "123456",
  "phone": "13800138000",
  "realName": "张三",
  "idCard": "110101199001011234",
  "createTime": "2025-04-06T08:00:00"
}
```

### 3. 查询用户

```
GET /api/users/{id}
```

### 4. 列车列表

```
GET /api/trains
```

预置数据（1 条）：
```json
[
  {
    "id": 1,
    "trainNumber": "G1001",
    "startStation": "北京南",
    "endStation": "上海虹桥",
    "price": 553.0,
    "totalSeats": 100,
    "availableSeats": 100
  }
]
```

### 5. 搜索列车

```
GET /api/trains/search?start=北京&end=上海
```

`start` 和 `end` 都是可选参数，按始发站/终点站模糊匹配。

### 6. 购票

```
POST /api/orders/buy?userId=1&trainId=1&passengerId=1
```

业务逻辑：扣减余票 → 创建订单 → 生成车票 → 状态流转（未支付 → 已支付 → 已出票）

响应：
```json
{
  "id": 1,
  "orderNo": "ORD1712304000000",
  "userId": 1,
  "trainId": 1,
  "passengerId": 1,
  "status": "已出票",
  "price": 553.0,
  "createTime": "2025-04-06T08:00:00"
}
```

### 7. 退票

```
POST /api/orders/{orderId}/cancel
```

业务逻辑：校验订单状态 → 恢复余票 → 更新订单状态 → 更新车票状态

响应：`"退票成功"` 或 `"退票失败：订单无效或已处理"`

### 8. 查询用户订单

```
GET /api/orders/user/{userId}
```

## 设计说明

### 数据存储

所有数据存储在 `DataService` 的内存 `ArrayList` 中，重启后数据即丢失。预置一条 G1001 列车（北京南→上海虹桥，553元，100座）。

### 订单状态流转

```
未支付 → 已支付 → 已出票 → 已退票
```

购票时自动完成"未支付→已支付→已出票"的流转；退票时置为"已退票"。

### 余票管理

`Train` 实体维护 `availableSeats` 字段，购票 `bookSeat()` 减一，退票 `refundSeat()` 加一，最低 0，最高不超过 `totalSeats`。

## 已知限制

- **无数据库**：数据纯内存存储，重启即丢失
- **无认证**：无登录/登出、无 Token 校验
- **无乘客管理 API**：`Passenger` 实体存在但无 Controller
- **固定座位**：购票固定分配 `01车01A`
- **无参数校验注解**：仅在 Controller 中做了简单空值判断
- **无全局异常处理**：错误直接抛 `RuntimeException`，返回 500
- **MySQL 依赖未使用**：`pom.xml` 中引用了 `mysql-connector-j` 但实际未连接数据库
