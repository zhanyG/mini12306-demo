# 数据库接入文档

## 背景

项目原使用内存（`ArrayList`）存储数据，每次重启数据丢失。本次改造为 MySQL 持久化存储。

---

## 改动文件清单

### 修改的文件（10 个）

| 文件 | 改动内容 |
|------|---------|
| `demo/pom.xml` | 添加 `spring-boot-starter-data-jpa` 依赖 |
| `demo/src/main/resources/application.properties` | 添加 MySQL 数据源和 JPA 配置 |
| `entity/User.java` | 添加 `@Entity`、`@Table`、`@Id`、`@GeneratedValue`、`@Column` 注解 |
| `entity/Passenger.java` | 同上 + 添加 `@NoArgsConstructor` |
| `entity/Train.java` | 同上 + 添加 `@NoArgsConstructor` |
| `entity/Order.java` | 同上 + 添加 `@NoArgsConstructor` |
| `entity/Ticket.java` | 同上 + 添加 `@NoArgsConstructor` |
| `service/DataService.java` | 重写：用 Repository 替换 ArrayList + AtomicLong |
| `service/OrderService.java` | 重写：直接注入 Repository 替代 DataService |
| `controller/UserController.java` | 删除手动 ID 生成，改为使用 save 返回的自动 ID |

### 新建的文件（5 个）

均在 `repository/` 包下：

| 文件 | 用途 |
|------|------|
| `UserRepository.java` | 用户数据访问，含 `findByUsername` 查询 |
| `TrainRepository.java` | 车次数据访问 |
| `OrderRepository.java` | 订单数据访问，含 `findByUserId` 查询 |
| `TicketRepository.java` | 车票数据访问，含 `findByOrderId` 查询 |
| `PassengerRepository.java` | 乘车人数据访问 |

---

## 数据库说明

- **数据库类型**: MySQL
- **表结构**: 由 Hibernate 在项目启动时自动创建（`ddl-auto=update`），无需手动建表
- **创建的表**: `users`、`passengers`、`trains`、`orders`、`tickets`
- **测试数据**: 项目首次启动时会自动插入一条车次数据（G1001 北京南→上海虹桥）

### 运行前准备

```sql
CREATE DATABASE mini12306;
```

> 数据库密码通过环境变量传入，不写在代码中。

### 启动

```bash
cd demo
mvn spring-boot:run
```

---

## 技术栈变更

| 项目 | 改前 | 改后 |
|------|------|------|
| 数据存储 | ArrayList（内存） | MySQL（持久化） |
| ORM 框架 | 无 | Spring Data JPA + Hibernate |
| ID 生成 | `AtomicLong` | `@GeneratedValue`（数据库自增） |
| 数据访问 | DataService 手动管理 | Repository 接口自动实现 |
