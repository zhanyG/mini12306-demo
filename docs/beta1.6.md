# mini12306 开发完善记录

## 1. 支付宝支付接入
- 集成支付宝沙箱 RSA2 签名，生成可扫码的支付页面
- 修复私钥格式（raw base64，去除 PEM 头）
- 新增改签补差价支付接口 `/api/pay/alipay/page-upgrade/{orderId}`
- 支付回调重定向地址可配置 `alipay.frontend-url`

## 2. 支付流程完善
- **购票**：创建未支付订单 → 弹窗选择支付方式（支付宝/模拟支付）
- **订单列表**：新增「未支付」标签，未支付订单可点击「去支付」
- **改签补差价**：涨价车次需补差价后才完成改签

## 3. 改签体验优化
- 改签弹窗支持按出发站/到达站搜索车次（不再限制同线路）
- 显示差价信息（补差价/退款），涨价需先支付
- 弹窗底部按钮随时可见（sticky）

## 4. 系统通知功能
- 后端：Notification 实体 + 用户已读记录表
- 管理端：新增通知管理（发布/删除系统通知）
- Web 前端：导航栏通知图标 + 未读角标 + 列表页 + 详情页 + 标记已读
- 移动端：TabBar 通知图标 + Vant 风格列表/详情 + 标记已读
- 已读逻辑：标记后未读数 -1，归零角标消失

## 5. 实名认证
- `IdCardValidator`：纯算法校验（GB 11643-1999 校验位），无第三方依赖
- 校验格式、出生日期、校验位，提取性别和出生日期
- Profile 页新增实名认证入口（Web + 移动端）

## 6. 账单系统
- Bill 实体记录 PAYMENT/REFUND/CHANGE_UPGRADE/CHANGE_REFUND
- 购票、退票、改签补差、改签退款均自动生成账单
- 账单列表页（Web + 移动端）

## 技术栈
- **后端**：Spring Boot 4.0.6 + JPA + MySQL 9.6
- **Web 前端**：Vue 3 + Vite 5（端口 5173）
- **移动端**：Vue 3 + Vant 4 + Vite 6（端口 5175）
- **管理端**：Vue 3 + Vite（端口 5174）
